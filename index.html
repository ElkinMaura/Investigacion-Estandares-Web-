Mi Proyecto CSS3

Demostración de diseño vertical con Flexbox y estilos individuales

Básico

Caja Roja

Usamos clases separadas (.caja-1, .caja-2, .caja-3) para darle a cada elemento un color de fuente diferente y un borde único.

Esto demuestra cómo la cascada y la especificidad en CSS nos permiten sobrescribir estilos generales.

Estructura

Caja Verde

El contenedor principal utiliza Flexbox con la propiedad flex-direction: column para apilar las cajas una debajo de la otra.

Esta es la manera moderna de estructurar el contenido sin usar los antiguos "floats".

Responsive

Caja Azul

Esta estructura vertical es ideal para dispositivos móviles, ya que facilita la lectura haciendo que el usuario solo tenga que hacer scroll hacia abajo.

Con Media Queries, controlamos el ancho máximo en computadoras.
